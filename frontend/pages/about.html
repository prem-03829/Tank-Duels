ABOUT TANK DUELS

Tank Duels is a browser-based turn-based artillery game where players aim, fire, and outmaneuver their opponents across destructible terrain.

Adjust your angle and power, account for the wind, and choose the right moment to fire. Every shot can change the battlefield.

GAME MODES

SAME DEVICE

Two players can battle on the same computer, taking turns and sharing the same battlefield.

ONLINE 1V1

Create or join an online battle using a battle code and compete against another player through the browser.

FEATURES

DESTRUCTIBLE TERRAIN

Shots can reshape the battlefield, making every round different as the terrain changes.

WIND & BALLISTICS

Angle, power, gravity, and wind all affect projectile movement and shot outcomes.

MULTIPLE BIOMES

Battle across different environments with procedurally generated terrain.

TRAJECTORY VIEW

Optional trajectory visualization helps players plan their shots before committing to a fire.

ACCOUNTS & PROFILES

Tank Duels supports optional player accounts for features that benefit from persistent data.

PLAYER PROFILES

Create a profile with a unique username and choose from built-in tank avatars or use a custom avatar.

STATISTICS

Completed online battles can contribute to persistent player statistics.

BATTLE HISTORY

Authenticated players can view their completed battles and results.

GUEST MODE

Players can start a game without creating an account. Guest gameplay remains local to the browser.

ONLINE 1V1

Online battles use server-authoritative game state to keep important battle actions synchronized between players.

Players can create a battle, share its battle code, and join from another browser. Battle state, turns, shots, damage, scores, and completed results are synchronized through the backend.

BUILT WITH

HTML5 CSS JavaScript Canvas API Python Flask Supabase PostgreSQL Vercel Render Umami

ANALYTICS

Tank Duels uses Umami Analytics to understand general website usage and improve the project.

Analytics are used to understand how the website is being used rather than to provide gameplay functionality.

PROJECT

Tank Duels is a student-built project created to explore browser game development, multiplayer synchronization, backend development, authentication, databases, and modern web technologies.
